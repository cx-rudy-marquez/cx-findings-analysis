What each setting decides

Opportunity weights
How much a High, Medium, Low or Info finding counts toward the score. Four weights and no Critical is deliberate, and the two absences are not the same kind: Info is weighted because Findings Analysis does evaluate Info results, so they are removable noise like any other. Critical is absent rather than weighted zero because the platform never evaluates it at all — a zero would read as a choice someone could argue with, when the severity is simply not eligible.
Migration risk thresholds
Re-onboarding a project means creating a new one, and a new project starts with no scan history. Low risk needs both counts small; High needs only one large — a project with 40 scans on one branch and one with 3 scans across 9 branches have each accumulated history worth keeping.
Re-base recommendation
Past this age, a project's baseline is flagged on the Projects list. A comparison anchored to an old baseline measures the intervening months of code alongside the capability, so the number stops being attributable. The default is 90 days.
